# Plan Link - one link for every page, in model / view / controller Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every page talks to the tank through one controller (`cqLink`), keeps tank data in one model (`TankModel`) that its views draw, and wires STOP the same way (on touch, never silently lost) - after the packer has made room by stripping comments.

**Architecture:** Shared parts inlined by `pack_web.py` as in R29 / R30: `tank_model.js` (model), `link.js` (controller), `strip.js` (view), `drive.js` (the drive page's model); `cqBar.onStop` for STOP input.

**Tech Stack:** plain HTML/CSS/ES5 packed by Python, node `--test`, Python unittest, Playwright MCP checks on `fake_tank.py` :8765.

**Spec:** `docs/lld/esp32-bridge-lld.md` R31, `docs/design-notes.md` §210, review `docs/reviews/2026-11-04-web-architecture-review.md`.

## Global Constraints
- Never weaken safety: every page's STOP keeps its messages (Drive `stop`; /logo, /ai, /settings `stop` + `logo_stop`; Help through `stopOnce`); Drive's §201 hide-STOP and R6 latch rules unchanged; STOP gains touch and the link-down fallback.
- Hello names unchanged: `basic-drive`, `logo`, `ai-page`, `settings`.
- Timings: ping 1 s; silence 4 s; backoff first 1000 ms (Drive) / 500 ms (others), doubling to 5000 ms; `wifi_status` every 10 s.
- No budget raised; ES5; no new dependencies.
- Commits: Conventional Commits, ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. Drive hidden while driving: `onHide` sends STOP before the link closes (§201), and only when it might be driving.
2. A WiFi drop with no close: 4 s later the page shows RECONNECTING and STOP uses its own socket.
3. A STOP pressed twice fast (pointerdown, then the click that follows): one stop per press, not two.
4. Reconnect storms: hidden / shown quickly - never two sockets open from one page.
5. Comment stripping: a `//` inside a string or a URL, and Help's `<pre>` blocks, survive.
