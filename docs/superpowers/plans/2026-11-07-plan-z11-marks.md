# Plan Z11 — the MARKS layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the `/ai` page shows what the engine makes of each picture - low obstacles red, high orange, free floor faint green - as a MARKS layer over the camera picture, the default layer.

**Architecture:** `HeightPoints.classify` also returns its per-pixel sort as a small class picture (`Marks.classes`); Perception calls the feed hook after seeing, with it; the feed frame carries it as a third part (`marks: [w, h]`); `ai.js` splits and colours it; `ai.html` draws it under a MARKS choice in VIEW B's layer select.

**Tech Stack:** Python 3.12 (uv, pytest, ruff, pyright strict), plain JS (node:test), the bridge's `pack_web.py`.

**Spec:** AI engine LLD §26, bridge LLD R33, design-notes §221. Branch `plan-z11-marks` (worktree `scratchpad/plan-z11-marks`, from `main` 0e3cf46).

## Global Constraints
- Classes: 0 nothing, 1 floor, 2 low, 3 high, 4 above; the grid is `classify`'s stride-4 grid of the depth picture.
- Colours: low red, high orange (~70 % over the picture), floor faint green (~25 %), above and nothing not drawn; nearest-neighbour scaling.
- The feed: marks only with a picture the map used; an old frame (no `marks`) decodes as before; a page ignores bytes it does not read.
- MARKS is the default layer; the choice remembered per browser in `cq_ai_layer` (localStorage in try / catch).
- `/ai` budget **32 KB** gzipped (owner, 2026-11-07, design-notes §221: "a").
- The map, the drive and every safety rule are unchanged.
- Commits: Conventional Commits ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. The feed hook now runs after seeing (off the event loop): a slow depth picture must not stall the camera pictures to the page more than before - the hook still runs once per picture, and a picture with no depth still goes out.
2. A frame with marks to an old page (or an old engine to the new page) must not break either.
3. The class picture's orientation: row 0 is the picture's top, as the camera picture.
4. A skipped picture (turning, camera moving) sends no marks; the page clears stale marks after 0.5 s.
5. localStorage blocked (private mode): MARKS still the default, no exception.
