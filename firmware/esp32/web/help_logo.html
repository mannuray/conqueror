[ TANK LOGO - QUICK REFERENCE ]

Write, check and run programs on the Logo page (☰ MENU → LOGO). The tank checks each program as you type and draws its path before anything moves; RUN goes straight through, STEP runs one line per press, STOP ends it at once.

MoveFORWARD n/FD, BACK n/BK (1-500 cm, needs the encoders) · RIGHT a/RT, LEFT a/LT (degrees, right is +) · ARC RIGHT a r (radius ≥ 31 cm) · PIVOT LEFT a · SPEED p (10-100 %) · HOME (face the start way again) · WAIT s (≤ 60 s)
Look / light / soundLOOK LEFT|RIGHT|UP|DOWN|HOME · LED GREEN (RED GREEN BLUE YELLOW PURPLE WHITE ORANGE OFF) · BEEP · SOUND HORN (the tank's 24 sounds) · PLAY [ C4 E4 G4 2 ] · SAY [ well done ]
SensorsDISTANCE (cm) · OBSTACLE? · BLOCKED? (the last move was stopped by something in the way) · HEADING · TILTED? · BATTERY · TIMER (s) · RANDOM n · REPCOUNT
LanguageREPEAT n [ ] · FOREVER [ ] · WHILE c [ ] · WAIT UNTIL c · IF c [ ] · IFELSE c [ ] [ ] · TO name :a … END (your own words, recursion allowed) · OUTPUT x · AND OR NOT · STOP ends the whole program · ; comment
Limits5 min run time · 8 KB of text · 64 words of your own · 100 calls deep (calls at the end of a word use no depth) · WAIT ≤ 60 s · FORWARD/BACK ≤ 500 cm per step
SafetyEvery move is a normal tank move: the obstacle brake, deadman, tilt and battery cut-offs apply. Something in the way ends the program unless it uses BLOCKED?. STOP from anywhere (this page, a phone, the IR remote, the STOP word) ends the program; hiding the Logo page ends a program started there.
